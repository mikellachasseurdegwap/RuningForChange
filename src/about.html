À propos

Ce projet est une intégration front-end inspirée d'une maquette Figma. L'objectif est de produire une structure claire, responsive et accessible, en respectant un workflow Git propre.

Vision

Mettre l'accent sur la lisibilité, la hiérarchie visuelle et la sobriété du design.

Méthode

Travail par issues, branches feature, commits clairs et pull requests.

Technologies

HTML, CSS et JavaScript natif. Aucun framework, focus sur les bases solides.

Qualité

Code structuré, responsive, accessible et maintenable dans le temps.
